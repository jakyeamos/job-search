## Conventions

- One doc per topic/company/theme. Prefer updating an existing doc over creating a near-duplicate.
- Filename: `{topic-slug}-{YYYY-MM}.md` for time-bound research, or `{topic-slug}.md` for evergreen/living docs (e.g. a single running lessons-learned file per theme).
- Every doc update -> add/update its row here (Last Updated + one-line Summary refresh).
- Job board search tool: `firecrawl-search` skill (Firecrawl CLI, initialized via `firecrawl init`) -- use for job board queries where WebSearch is insufficient or rate-limited.
