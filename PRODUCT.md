# Daily Career Queue

## Register

product

## Users

Jakye Amos, using a private career command center during a morning job-search session. The user needs to review a small, ranked set of roles without losing context or accidentally submitting an application.

## Product Purpose

The Daily Career Queue turns verified job leads into a focused, human-controlled next-action list. It should make the next decision obvious: open the role, mark it applied, skip it, or snooze it. The system refreshes from the existing career-ops pipeline and Gmail intake, while preserving the user as the final approver for every application.

Success means the user can open one quiet surface, understand why each role is present, take action in under a minute, and leave a trustworthy record in the existing application tracker.

## Brand Personality

Calm, focused, low-friction.

## Anti-references

- No gamified job-search dashboard, streaks, confetti, or motivational pressure.
- No noisy SaaS wall of identical cards, decorative gradients, or oversized metric hero.
- No automation language that implies an application was submitted when the user only opened or reviewed a role.
- No public-facing portfolio styling; this is a private working surface.

## Design Principles

1. Put the next decision at hand: every role should have a clear, reversible action.
2. Show evidence with the role: score, lane, source, liveness, and fit reasons stay visible.
3. Preserve human control: opening a role never changes its status; only explicit actions do.
4. Prefer quiet density: reduce scanning effort without hiding important context.
5. Keep the source of truth singular: the UI reads and writes the existing queue state and application tracker.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. All actions must be keyboard reachable with visible focus states. Use text plus color for status, support reduced motion, preserve readable layouts on narrow screens, and provide explicit loading, success, error, and empty states.
